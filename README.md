## Open source projects

### PM OS: shared context for product work

[`PM-operating-OS`](https://github.com/Sach1ng/PM-operating-OS)

A self-serve setup so the model starts with your strategy, goals, and tools instead of a blank chat. Runs on Cursor and Codex.

- Onboarding writes your config from role, goals, and tools
- Skills for PRDs, experiments, launch, exec updates, retros, and decisions
- Knowledge layer for strategy, customer segments, and metrics
- Memory that carries decisions, feedback, and plans across sessions
- MCP connections to the tools you already use (Slack, Jira, Google Drive, Figma, and others)

Earlier version, the one the memory post is about: [`PM-operating-OS-memory`](https://github.com/Sach1ng/PM-operating-OS-memory)

### Pip: one AI coworker on Slack, desktop, and Chrome

[`tandem`](https://github.com/Sach1ng/tandem) · [site](https://sach1ng.github.io/tandem/)

Brings the agent to the work, instead of making you bring the work to the agent. Three surfaces, one engine, one local memory.

- Slack (`@Pip`), a desktop widget, and a page-aware Chrome extension
- Engine is a thin adapter around the Cursor CLI, so the model is a setting
- Memory is plain markdown on your machine. You can open and read every line
- Optional mount of PM OS as the starting brain. Blank memory works on day one

### Eval Kit: gold, confirmed metrics, then pre-prod and prod

[`Eval-Kit`](https://github.com/Sach1ng/Eval-Kit)

Most eval tools assume you already have gold. This one helps you create it from interviews or past transcripts, propose metrics you confirm, score pre-prod against that gold, and watch unlabeled production traces.

- Worlds from an interview or ingested tickets; drafts are not gold until checks and a known-good run
- Metrics come from the job, harm, and the PRD — conversion stays an experiment, not a gate
- A right-looking answer on the wrong path is dirty, not a pass
- `preprod` / `ship` / `prod`. No API key. No LLM judge

### Otira: AI coworkers for small businesses

[`otira`](https://github.com/Sach1ng/otira) · [site](https://sach1ng.github.io/otira/)

Forward-deployed coworkers for SMBs. A context layer and connectors on the tools a company already uses, then automations on top. Pre-revenue. Wine first, then other verticals.

### better_slido: a presentation coworker

[`better_slido`](https://github.com/Sach1ng/better_slido)

Browser slide editor with an always-on agent you can @-tag. You comment on blocks and accept or reject edits. Pre-alpha: architecture and plan. Code is not written yet.
